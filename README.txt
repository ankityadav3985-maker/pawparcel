PAW PARCEL — PET SUBSCRIPTION WEBSITE

Files in this folder:
- index.html — main website page
- app.js — interactive frontend behaviour
- pet-hero.png — hero image asset

HOW TO OPEN
Keep these three files together. Open index.html in a browser, or run a simple static web server from this folder, for example:
  python -m http.server 8000
Then visit http://localhost:8000

The prototype includes a responsive subscription dashboard, editable delivery frequency, product quantity controls and live totals, add-on items, delivery tracking, skip/pause/resume interactions, pet profile controls, and browser-local persistence.

This is a frontend demo; it does not connect to a real account, payment provider, inventory, or delivery service.
